# Shipay Back-End Engineer Challenge

Repositório criado para o desafio de back-end da Shipay. 

O objetivo é responder as questões propostas no arquivo challenge.md, nas propostas de soluções são com base em meu conhecimento utilizando a linguagem python. Utilizou-se a mesma para os desafios de código adjunto ao framework FastAPI e o banco de dados SQLite quando preciso.

Respostas descritivas estão na pasta solutions com número da questão.

Respostas de código estão na pasta implementation.
